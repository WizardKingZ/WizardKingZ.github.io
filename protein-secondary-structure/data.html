Each protein becomes a fixed-width sequence of residue labels

Data and objective

Bottom lineThe input is a variable-length amino-acid sequence; the target is a parallel Q8 label sequence. Padding standardizes the tensor shape, and the custom metric removes padded positions from evaluation.

Input

Amino-acid sequence

Each row contains a protein sequence and its residue-level expected labels.

→
Encode

Tokenize n-grams

The reusable code supports n-grams; the executed `main.py` sets n = 1.

→
Shape

Pad or truncate

Short sequences are post-padded; long sequences are pre-truncated to 512 positions.

→
Target

Classify each residue

A nine-way softmax represents eight Q8 states plus padding.
